# 🚀 Clone LinkedIn

Progetto frontend sviluppato in team con l’obiettivo di ricreare fedelmente l’interfaccia di LinkedIn, replicando layout, navigazione e principali funzionalità social come feed, profilo utente, connessioni e ricerca, con gestione dinamica dei dati tramite API.

---

## 🧠 Overview

- Clone frontend dell’interfaccia di LinkedIn
- Riproduzione fedele di feed, profilo e navbar
- Sistema di post e visualizzazione contenuti social
- Gestione profilo utente e connessioni
- Funzionalità di ricerca utenti e contenuti
- Integrazione API per dati dinamici
- Focus su UI/UX e struttura realistica del social network

## ⚙️ Tech Stack

### 🌐 Frontend
- React
- Redux
- Sass / CSS
- Bootstrap

### 🧪 Tools
- Node.js
- Git

## 🔐 Features

- Feed principale con post dinamici
- Profilo utente con informazioni e attività
- Sistema di pubblicazione e visualizzazione post
- Sidebar con suggerimenti e connessioni
- Barra di ricerca utenti/contenuti
- Interfaccia fedele al design LinkedIn
- Gestione dati tramite API

## ⚙️ Setup

### 📦 1. Clona il progetto
```bash
git clone https://github.com/luke-wb/BuildWeek2-Spotify.git
```

### 🌐 2. Installa il progetto
```bash 
npm install
```

### 🚀 3. Avvia il progetto
```bash 
npm start
```
